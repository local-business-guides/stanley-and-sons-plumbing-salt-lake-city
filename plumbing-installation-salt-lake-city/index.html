What to have ready

A little preparation can save time when you call. Gather the details you know, and leave the diagnosis to a plumber.

  • Name the fixture or plumbing item you want installed, if known.
  • Describe the room and the general location where it will go.
  • Say whether this is a replacement or a new addition.
  • Note any visible leak, damaged fitting, or difficulty using the existing setup.
  • Mention access concerns, such as items that need to be moved before the area can be reached.

Avoid buying materials based only on a guess about size or connection type. Also avoid starting removal if you aren't sure how to shut off the water or protect the area. If the existing plumbing is wet, damaged, or difficult to reach, pause and ask for professional guidance before proceeding.
